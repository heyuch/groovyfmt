## design.md 里值得单独一提的部分

- **§3 三个决定架构的实测事实**：为什么必须走 token 重排而不是 AST 重打印
- **§11 与 §15 是更正章节**：明确记录了 PoC 落地后**被证伪的结论**，不是事后美化的叙事
- **§16–§18 是接续踩坑**：Spotless 类加载器障碍、多 module 拆分、自定义 CodeNarc 规则
- **附 A**：复现本文所有实测数据的命令
